# AirFake 0.1

Первый прототип твика для iPhone X / iOS 16 / Dopamine (rootless).

Что уже есть:
- инжект в SpringBoard;
- карточка в стиле системного Bluetooth-popup;
- правило по подстроке имени Bluetooth-устройства;
- по умолчанию ищет `Soundcore`;
- строка `Soundcore Liberty 4 NC`, `soundcore Q30`, `SOUNDCORE ...` совпадёт;
- ручное название на карточке;
- кнопка `Показать тестовую карточку` в Настройки → AirFake;
- карточка сама скрывается через 5 секунд.

## Важно

Это версия 0.1. Приватные Bluetooth-уведомления Apple могут отличаться между сборками iOS 16.
Именно поэтому в настройках есть тестовая карточка:
1. Если тестовая карточка показывается, сам твик и UI работают.
2. Если тест работает, а подключение наушников не ловится, нужно снять реальные имена Bluetooth-уведомлений на твоём iPhone X и добавить их в `Tweak.xm`.

## Сборка

### macOS
Нужны Theos и Xcode/iOS SDK.

```bash
export THEOS=~/theos
cd AirFake-0.1-source
make clean package FINALPACKAGE=1
```

### Linux / WSL
Нужны Theos, iOS toolchain и iOS SDK для Theos.

После установки Theos:

```bash
export THEOS=~/theos
cd AirFake-0.1-source
make clean package FINALPACKAGE=1
```

Готовый `.deb` появится в папке:

```text
packages/
```

## Установка на iPhone

Самый простой способ:
1. Передать `.deb` на iPhone.
2. Открыть файл через Sileo или Filza.
3. Установить пакет.
4. Сделать Respring.
5. Открыть `Настройки → AirFake`.
6. Нажать `Показать тестовую карточку`.

Для страницы настроек нужен `PreferenceLoader`.

## Проверка Soundcore

В `Настройки → AirFake`:
- `Включить AirFake`: ВКЛ.
- `Искать в имени`: `Soundcore`
- `Название на карточке`: например `Soundcore`

После подключения наушников с именем вроде:
- `Soundcore Liberty 4 NC`
- `soundcore P40i`
- `SOUNDCORE Q30`

AirFake должен показать одну и ту же карточку.
